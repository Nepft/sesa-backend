# Folder artefak model

Letakkan artefak model final `sesa_model.joblib` (hasil ekspor dari Colab)
di folder ini. Artefak `.joblib` besar **tidak di-commit** ke repository
(lihat `.gitignore`); hanya berkas pendukung kecil seperti `.gitkeep` yang
ikut ter-commit.

Cara menghasilkan artefak: jalankan `scripts/export_model_colab.py` di Colab,
lalu unduh hasilnya ke `model/sesa_model.joblib`.
